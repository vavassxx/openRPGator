## P0 — корректность уже заявленных возможностей

- [x] **Единицы `TileGrid`.** Мировые координаты движка заданы в тайлах, а
  `RMap.tileSize` — размер тайла в пикселях для рендера. `GameRuntime` больше не передаёт
  пиксельный размер в `TileGrid`; добавлен регрессионный тест с `tileSize = 32`.
- [ ] **Редакторы не теряют данные карты.** При пересборке `RMap` сохранять `portals()`
  (desktop `EditorFrame`, Android `MapEditorActivity`), добавить отдельный collision-слой,
  создание/редактирование порталов. Сейчас collision пишется в слой 0, а порталы исчезают
  после первого изменения.
- [ ] **Порядок инициализации региональных сервисов.** `UiSink`, `PlayerStore` и
  `RegionTransitionSink` должны быть установлены до выполнения `world.lua`. Сейчас
  `ServerHost` подключает их после `regions.load()`, поэтому `engine.notify/save_player/
  transition` из загрузочного скрипта не работают.
- [ ] **Android smoothing не должен менять authoritative snapshot.** `GameView.onDraw`
  записывает сглаженные координаты обратно в `snapshot`; каждый кадр сглаживание применяется
  повторно. Хранить отображаемые позиции отдельно, как в desktop-клиенте.

## P1 — регионы, сеть и сохранения

- [ ] **Детерминированный порядок регионов.** `RegionCatalog` использует `Map.copyOf`, из-за
  чего порядок `all()` нестабилен, а `RegionManager.load()` выдаёт namespace-базы в этом
  порядке. Использовать `LinkedHashMap`/сортировку.
- [ ] **Регистр `.rmap` в каталоге регионов.** Фильтр расширения регистрозависим, а проверка
  наличия регионов в `ServerHost` — регистронезависима. Приводить имена к lower-case
  согласованно.
- [ ] **Валидация порталов и карт.** Проверять finite/границы координат порталов, размеры
  слоёв, количество тайлов и сущностей в `RMapIO`; не принимать битые карты молча.
- [ ] **Миграция игрока между регионами.** Не терять компоненты при откате миграции; сохранять
  `Name`, `Transform`, `Collider`, `Scale` и другие переносимые компоненты; предусмотреть
  Lua-хуки `on_region_leave` / `on_region_enter`.
- [ ] **Совместимость старых сейвов.** `FilePlayerStore` хранит только SHA-256 ключа, а
  `LuaApi` всегда приводит имя к lower-case. Добавить fallback для сейвов со смешанным
  регистром, не ломая новые ключи.
- [ ] **Ограничения действий и блокировки.** `Cmd` и `DialogResponse` не проходят через
  `ActionLimiter`; `Client.send()` под `worldLock` может блокировать тик. Ограничить частоту
  команд и не держать world-lock во время сетевой записи.
- [ ] **Ошибка bind не оставляет сервер полузапущенным.** При исключении в `ServerHost.start`
  останавливать tick-поток/executor и освобождать сокет.

## P1 — серверный начальный зум

- [x] **Сервер задаёт стартовый зум игрока.** `engine.set_zoom(zoom)` в `world.lua` задаёт
  масштаб камеры для региона; сервер передаёт его клиенту вместе с `MapPacket`, в том числе
  после перехода между регионами. Desktop/Android применяют значение как начальный уровень,
  но не блокируют ручной зум пользователя.
- [ ] **Динамическое изменение зума на лету (при необходимости).** Если понадобится менять
  масштаб конкретному игроку после входа, добавить отдельный пакет/метод вместо повторной
  отправки карты.
